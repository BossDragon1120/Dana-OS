# Routine: learning-notes-intake

**Schedule:** weekly, Sunday (Pacific)
**Track:** all
**Status:** 💡 proposed (turn on once there are notes marked `status: done`)
**Runs:** the [`learning-notes-intake`](https://github.com/BossDragon1120/Little-Panda-Education/blob/main/agents/learning-notes-intake.md) agent

## Inputs
- Upskilling-and-Subject-Matter-Expertise: module notes, topic notes, glossary
- Book-and-Podcast-Whispers: reflections and episode notes

## Outputs
- Up to 3 scripts or video briefs
- Updated `video` fields on the source notes
- One summary message to me

## Prompt
```
Run the learning-notes-intake agent from github.com/BossDragon1120/Little-Panda-Education
(agents/learning-notes-intake.md). Follow it exactly. Send me one summary message.
```

## Guardrails
The only edit allowed in the notes repos is the `video` field. Never post.
